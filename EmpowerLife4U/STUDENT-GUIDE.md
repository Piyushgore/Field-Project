# EmpowerLife4U — Student Guide

This project uses plain HTML, CSS, and vanilla JavaScript.

- `client/index.html` is the document shell and loads the fonts and JavaScript entry point.
- `client/src/main.js` renders the homepage and workout pages, then attaches BMI, schedule, menu, reveal, form, and WhatsApp behavior.
- `client/src/styles.css` contains the complete visual system, with comments grouping navigation, hero, sections, cards, and responsive rules.

To explain the project, start with `main.js`, then follow the matching section comments in `styles.css`. The project intentionally avoids React components and framework-specific state so the page flow is easy to trace.
